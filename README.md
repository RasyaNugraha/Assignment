# Fabulari

Multi-user text-and-image chat application built with the MEAN stack (MongoDB, Express, Angular, Node.js)
for 3813ICT Full Stack Development.

## Status

Phase 1 in progress — planning, design, and admin/user-management prototype (no live chat yet).

## Docs

- [Requirements Specification](docs/REQUIREMENTS.md)
- [Screen Planning / Wireframe Notes](docs/WIREFRAME.md)

## Phases

- **Phase 1** (Week 7 demo): user registration/login, group & room creation requests, admin approval flows.
- **Phase 2** (Week 12 demo): real-time chat via Socket.IO, MongoDB persistence.
